# Vórtex Color

**Tus colores, sin límites.** App de Vortex Company, parte de la suite Vórtex Studio.

Herramienta de color para diseñadores, estudiantes y creadores: canvas + k-means, sin servidor.

- **Paleta de imagen**: sube o arrastra una foto y extrae de 3 a 12 colores dominantes con k-means (recalculable al instante).
- **Color y armonías**: selector manual con conversiones HEX / RGB / HSL copiables y armonías complementaria, análoga, tríada, tetrádica y tonos.
- **Contraste WCAG**: ratio entre dos colores con veredictos AA/AAA para texto normal y grande, con vista previa real.
- Todo se copia al portapapeles con un clic.

## Características

- Gratis, sin anuncios y sin rastreo.
- 100% local: las imágenes se analizan en tu navegador y nunca se suben.
- Compatible con PC y móvil.
